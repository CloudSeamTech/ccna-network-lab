# CCNA Network Engineering Lab

Work through 20 browser lessons on networking fundamentals, subnetting, rack installation, cabling, Cisco IOS, and troubleshooting. Start with **Rack a switch**, then use **Next** to move through the course.

## Run the lab

Open `index.html` in a browser, with the JavaScript and stylesheet next to it. For GitHub Pages, publish the `main` branch from `/ (root)`.

The terminal is a guided simulation. The rack and patch-panel diagrams illustrate the workflow. Follow the hardware manufacturer's instructions for your specific equipment.
